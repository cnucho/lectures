# 정책연구자를 위한 텍스트 분석 실습

정책전문가가 텍스트 분석을 연구설계와 정책효과 평가에 연결하는 방법을 설명하는 강의 자료다. `고립·은둔 청년 정책`을 예로 들어 연구질문 설정, 자료 범위 결정, 분석방법 점검, 실패 진단과 제한된 결론 도출을 순서대로 다룬다.

## 수업의 역할 분담

- Evidence Ledger: 검색전략, 자료수집, 출처 기록, 망라성 점검과 분석 코퍼스 확정
- Text Analysis Copilot: 확정된 코퍼스의 N-gram, 코딩, 신뢰도 점검, 토픽·담론 분석과 근거 연결 해석

자동 분석만으로 정책효과를 입증할 수는 없다. 정책연구자는 비교설계, 분석단위, 분모, 누락자료와 대안 설명을 함께 점검해야 한다.

## 권장 강의 흐름

1. 슬라이드 1~5: 연구문제와 전체 워크플로
2. 슬라이드 6~13: 세 가지 정책 연구질문과 필요한 자료
3. 슬라이드 14~18: 첫 분석의 실패와 연구설계 수정
4. 슬라이드 19~20: Evidence Ledger와 Text Analysis Copilot 실행 화면
